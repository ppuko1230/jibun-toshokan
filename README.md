# 自分図書館 — 開発用ソース

友人が自分用の Mac 版を検討するための**移植の出発点**です。Windows 版 1.3.21 のソースから、教材と個人データを除いて新しいスナップショットを作りました。旧称「余白 / yohaku」の識別子は互換性のためコード内に残っています。

## 現在の状態

- Node.js 22.23.4 と固定依存で、**空の教材と空の配色をビルド時だけ差し込む画面・サーバーの隔離バンドル検証**に成功しています。
- **アプリ起動、完全な配布ビルド、Mac での動作は未確認**です。検証用バンドルは実行・配布用ではありません。
- PDF.js 本体、フォント、イラスト、アイコン、ランチャー、同梱 runtime、教材 PDF は含みません。PDF 表示や元のデザインはそのままでは動きません。元素材をリポジトリへ含めずに取得・代替する方針は [BUILDING.md](BUILDING.md) を参照してください。
- 個人の教材、メモ、DB、設定、バックアップ、署名秘密鍵、過去 Git 履歴は含みません。

`PUBLIC-FILES.txt` がこのスナップショットの公開ファイル一覧です。`package.json` と `package-lock.json` に依存を固定しています。Windows 専用の起動、署名・更新、パス、Node 実行ファイルの検証処理は Mac 向けに作り直す必要があります。
